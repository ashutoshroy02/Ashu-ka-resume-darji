# Job Description: Junior Data Engineer

## Company: EngiNeo Solutions
## Location: Gurgaon
## Experience: 0-1 years

### Role Summary
Junior Data Engineer to build and maintain ETL pipelines, design data models, and contribute to enterprise-wide data ontology initiatives. Focus on understanding and representing data meaningfully across business domains (Finance, HR, Operations).

### Key Responsibilities
- **ETL Development**: Design/maintain ETL pipelines (Python, SQL, APIs, Cloud Storage). Use frameworks like Spark, Airflow, or AWS Glue.
- **Data Modeling**: Design conceptual/logical/physical models (Star/Snowflake schema). Support MDM strategies.
- **Data Ontology**: Develop taxonomies and standardized vocabularies. Contribute to knowledge graphs (Neo4j) and semantic data layers.
- **Collaboration**: Work in Agile environment with analysts and data scientists.

### Requirements
- B.Tech/B.E. in CS/IT/Electronics.
- Proficiency in Python and strong SQL (joins, aggregations, window functions).
- Basic understanding of ETL and RDBMS (PostgreSQL, MySQL).
- Interest in Data Ontology (entities, relationships).

### Good to Have
- Cloud platforms: AWS (S3, Glue, Redshift), GCP (BigQuery), or Azure.
- Apache Spark, Airflow, or Pandas.
- Knowledge of Graph Databases (Neo4j).
- Data Governance/Cataloging.
